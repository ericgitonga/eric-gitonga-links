# eric-gitonga-links

A single-page index of everything Eric Gitonga is currently building and shooting —
software/AI products, event platforms, and photography — since no one project or
domain tells the full story on its own.

Stopgap home for [ericgitonga.com](https://www.ericgitonga.com/) while that domain is
in limbo. Static HTML, no build step, deployed straight to Vercel.

## Updating

Edit `index.html` directly and push — Vercel redeploys on push to `main`.
